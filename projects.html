2026
Application Portfolio Management · IT Governance tooling

An interactive web dashboard that turns the company's Application Portfolio Management workbook into something leaders can explore: portfolio health, TIME assessment, technology risk, integrations and the modernization roadmap, all in one place.

Excel workbook→Python ETL→JSON snapshot→React dashboard

Dentalogic8

08/2025 – Present
Mobile app · AI/ML model

Detects dental caries from intraoral photos, classifies them on the ICDAS scale (D0–D6) and recommends treatment, built for people with limited access to dental care. The AI runs fully on the phone, so no internet connection is needed.

  • Benchmarked YOLOv12 variants combining 3 backbones (R-ELAN, MobileNetV3-small, EfficientNetB0) with 3 necks (FPN, BiFPN, PANet), tuned with Optuna on an NVIDIA H200.
  • Exported the best model to ONNX for on-device inference and built two clients: React Native (Expo) and Flutter.
  • Camera scan and photo upload, bounding boxes on detected lesions, analysis detail and saved check-up history.
  • Android APKs split per CPU architecture, with an installation guide for non-technical users.
